Summer 2026 Project
Dnd Wizard creator 

This is a summer project between Programming II and Data Structures that aims to implement concepts taught through 
class with a little exploration in software engineering using inheritence, public, private, and protected classes. 

This program will initially check for two files, Spellpool.dat and Character.dat. If found, it will allow the user 
to "play the game". If not found, the main menu will appear. From there, the user needs to create a spell pool under 
[s] Spells. Once the pool is created, it will be accessed from the character creator to pick a number of spells. The 
specific number is calcuated through the character's skills. 

To run, copy and paste the files within a visual studio project folder. To access this, right click the resources within
the project heirarchy, then click add existing. This will open a window into the directory which these files need to be 
placed into.
